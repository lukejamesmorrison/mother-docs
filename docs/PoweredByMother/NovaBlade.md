# Nova Blade Mk1

The Nova Blade Mk1 is a demonstration aircraft for the synergy of [Mother OS](../IngameScript/IngameScript.md), [Mother GUI](../MotherGUI/README.md) and [Mother Autopilot System (MAPS)](../MotherAutopilotSystem/README.md), all built using the [Mother Core](../Framework/README.md) framework.
