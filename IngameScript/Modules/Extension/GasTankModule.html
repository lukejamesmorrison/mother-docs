Gas Tank Module

The Tank Module allows the user to control Oxygen and Hydrogen tanks on their grid.

  • Commands
    • stockpile
    • share
    • toggle
  • Properties

Commands

stockpile

Set the Tank Stockpile to on.

tank/stockpile <Tank|Group>

Example

Terminal
tank/stockpile HydrogenTank;

share

Set the Tank Stockpile to off. The tank is now sharing its contents with your grid.

tank/share <Tank|Group>

Example

Terminal
tank/share OxygenTank;

toggle

Toggle the Tank Stockpile between on and off.

tank/toggle <Tank|Group>

Example

Terminal
tank/toggle HydrogenTank;

Properties

Tips

Properties and predicates are very useful in conditions. A property is compared with an operator and a value (fill < 25%), while a predicate stands alone (low). See Conditional Logic to use them in when rules and if steps.

A group of tanks is compared by its average fill.

PropertyDescription
fillHow full the tank is as a ratio, from 0 to 1. Compare with a percentage, ie. fill < 25%.
stockpile1 when the tank is stockpiling, 0 when it is sharing.
PredicateTrue when
lowFill is under 15%. Has a 5% buffer.
criticalFill is under 10%. Has a 3% buffer.
emptyFill is under 2%.
fullFill is over 98%.
stockpilingThe tank is stockpiling.

Compare a property

Mother > Custom Data
[rules]
HalfFuel=
| when "Hydrogen Tanks" fill < 50%;
|   light/color "Fuel Light" yellow;

Use a predicate

Mother > Custom Data
[rules]
LowFuel=
| when "Hydrogen Tanks" low;
|   light/color "Fuel Light" red;
| else;
|   light/color "Fuel Light" green;
