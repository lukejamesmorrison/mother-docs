Flight Control Module

This module manages autopilot and various flight characteristics of your grid. For this module to function, the grid must have a Remote Control block.

  • Commands
    • start
    • stop
  • Properties

Commands

start

Engage the autopilot system, enabling the grid to fly autonomously if a Flight Plan is loaded.

fcs/start [--options]

Options

OptionValuesUnitDescription
speed0 - maxm/sSet the maximum speed of the grid.

Example

Terminal
fcs/start --speed=50;

Tips

By default, the max speed is 100 m/s, though you can use mods like Configurable Parameters to change this. I highly recommend it and typically set the max speed to 300 m/s for small grids, and 500 m/s for large grids.

stop

Disengage the autopilot system.

fcs/stop

Example

Terminal
fcs/stop;

Properties

MAPS registers the properties and predicates of your ship with conditional logic. Use grid as the target, which is the grid's controller (a cockpit or remote control). Because Mother Core shares conditions across the construct, Mother OS and Mother GUI can use them too, as long as MAPS runs on the same construct.

NameTypeDescription
speedPropertyThe speed of the grid in m/s.
gravityPropertyThe strength of the planet's gravity in m/s². It is about 9.8 at 1 g, and 0 in space.
altitudePropertyThe height above the planet's surface in metres. It has no value in space, so a condition on it is false there.
movingPredicateThe grid is faster than 0.1 m/s.
stoppedPredicateThe grid is not faster than 0.1 m/s.
inspacePredicateThere is no gravity (gravity == 0).
ingravityPredicateThere is gravity (gravity != 0).
Mother OS > Custom Data
[rules]
LandingLights=
| when grid altitude < 100 --buffer=20 --for=2;
|   block/on "Landing Lights";
| else;
|   block/off "Landing Lights";

Atmosphere=
| when grid inspace --for=3;
|   block/off "Atmospheric Thrusters";
|   block/on "Hydrogen Thrusters";
| else;
|   block/on "Atmospheric Thrusters";
|   block/off "Hydrogen Thrusters";
Terminal
; Inside a routine, use if to branch on the ship's state
if grid speed > 30; light/color "Speed Light" red; end;

See the Space Transition and Landing Lights examples.
