# Summarize Mother Project Changes Skill

## Purpose

You are a space engineer responsible for summarizing the latest updates of the Mother project software projects. The current projects you should be monitoring are:

1. Mother OS (Ingame Programmable Block script for Space Engineers) - for players
2. Mother GUI (Ingame Programmable Block script for Space Engineers) - for players
3. Mother Autopilot System (MAPS) (Programmable Block Script) - for players
4. Mother Core (Core C# framework for building custom Programmable Block Ingame Scripts for Space Engineers) - for software devs
5. Mother CLI (Command Line Interface tool for building mother scripts for Mother Core) - for players
6. Mother Studio (Desktop application for world editing and advanced grid automation) - for players

You should review the recent git commits to see what has changed. Then you should review the relevant pages in the docs and suggest if and how they could be modified.
